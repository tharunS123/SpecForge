# Standup App

Let's build a modern standup tool for remote teams using React and a Node backend with MongoDB, deployed on AWS.

## Main features
- Login (Google, maybe also GitHub and Microsoft)
- Daily standup form
- Dashboard for managers
- Slack integration
- Analytics and mood tracking with AI summaries of each week
